🎙️ 2D 아파트 도면 AI 디지털화 파이프라인 발표 스크립트

발표자: 오현 (숭실대학교 소프트웨어학과)
참고: 2분반_8조.pdf 흐름 기준

[슬라이드 1: 타이틀]
안녕하세요.  소프트웨어학과 오현입니다. 
저희 조의 프로젝트 주제는 "2D 아파트 도면 AI 디지털화"입니다.
과거의 낡은 종이 도면, 즉 레거시 2D 평면도를 딥러닝을 통해 구조화된 디지털 데이터인 JSON으로 자동 변환하는 AI 베이스라인 모델을 구축하는 과정을 담았습니다. YOLOv8을 기반으로 객체를 탐지하고, 도메인 갭을 극복해 낸 실험 과정들을 순서대로 말씀드리겠습니다.

[슬라이드 2: 하드웨어 & 소프트웨어 스택]
먼저 개발 환경입니다. 
방대한 고해상도 도면 데이터를 처리하기 위해  고성능 환경을 활용했습니다. 
소프트웨어로는 빠르고 정확한 실시간 객체 탐지 알고리즘으로 유명한 YOLO(You Only Look Once)의 최신 버전인 YOLOv8m 모델을 메인 프레임워크로 채택하였으며, 특히 150 에폭의 강도 높은 학습을 진행하면서도 GPU 병목 현상을 방지하기 위해 배치 사이즈 32, 워커 8의 하드웨어 맞춤형 세팅(PRO 모드)을 적용했습니다. 이를 통해 1 에폭당 단 12초라는 극한의 훈련 효율을 달성했습니다.

[슬라이드 3: 프로젝트 개요 및 아젠다]
이번 프로젝트의 핵심 목표는 단순한 객체 탐지를 넘어, 최종적으로 위상학적 후처리(Topological Post-processing)까지 거친 구조화된 JSON 데이터를 얻는 것입니다.
우측에 보이시는 것처럼 실험은 크게 5개의 파트로 진행했습니다. 데이터 전처리부터 시작하여 데이터 수렴 확인, 도메인 증강, OCR 전이 학습, 그리고 실전 추론을 통한 최종 JSON 구조화까지의 흐름입니다. 
저희가 직접 전처리를 통해 구축한 마스터 데이터셋은 총 1,500장이며, 학습, 검증, 테스트 셋을 8:1:1 비율로 분할했습니다. 탐지 대상은 가구 및 구조물 7종에 텍스트 박스를 탐지하는 OCR 1종을 더해 총 8개의 클래스로 구성했습니다.

[슬라이드 4: 데이터 전처리 — 트러블슈팅]
프로젝트를 시작하며 가장 먼저 맞닥뜨린 난관은 '데이터 전처리'였습니다.
초기 AI 허브에서 다운로드한 원본 파일들은 이미지와 정답지(JSON) 파일명이 서로 맞지 않고 불규칙하게 흩어져 있어 단순 매칭 시 심각한 데이터 오염이 발생했습니다.
이를 해결하기 위해, 저희는 모든 파일의 CRC32 해시값과 파일 크기를 전수 조사하여 교차 검증하는 강력한 데이터 파이프라인을 새롭게 구축했습니다. 
또한 하드웨어 용량 폭발(OOM)을 막기 위해 무거운 PNG 이미지를 50% 축소하고 WebP 포맷으로 압축 최적화하여 퀄리티 손실 없이 디스크 I/O 속도를 비약적으로 끌어올렸습니다.

[슬라이드 5: Phase 1. Data Scaling — 최적 데이터 양 탐색]
다음은 Phase 1, 최적의 데이터 양을 탐색하는 실험입니다.
단순히 '데이터가 많으면 무조건 좋은 것일까?'라는 의문을 공학적으로 검증하기 위해, 학습 데이터를 300장부터 1,500장까지 점진적으로 늘려가며 성능을 측정했습니다.
그래프를 보시면, 데이터가 증가함에 따라 mAP@50 지표가 0.244에서 시작해 0.598까지 우상향하며 아름답게 수렴하는 것을 확인하실 수 있습니다. 이를 통해 무지성으로 데이터를 투입하는 대신 과적합을 막고 최상의 성능을 낼 수 있는 '1,200장'을 최적의 Train 데이터 규모로 확립했습니다.

[슬라이드 6: Phase 2-A. Augmentation — Clean Validation 비교]
Phase 2에서는 우리의 진짜 타겟인 '오래된 레거시 도면'을 위한 데이터 증강 효과를 검증했습니다.
먼저, 아주 깨끗한 검증셋(Clean Val)을 기준으로 증강을 전혀 하지 않은 순정 모델과, 증강을 거친 모델을 비교해보았습니다. 증강 모델에는 오래된 도면의 특성을 살려 무작위 색상 변형, 스캔 노이즈, 해상도 저하 등을 반영했습니다.
좌측 하단의 결과를 보면 깨끗한 도면에서는 증강 모델의 성능이 소폭 하락하며 순정 모델이 오히려 우세했습니다. 그렇다면 이 증강 기법은 실패한 것일까요? 

[슬라이드 7: Phase 2-B. Simulated Legacy Test — 도메인 갭 극복 실전 증명]
그 해답은 바로 이번 Phase 2-B 슬라이드에 있습니다.
저희는 기존 깔끔한 테스트셋 50장에 황변, 가우시안 노이즈, 해상도 저하를 인위적으로 적용한 '가상 레거시 테스트셋'을 만들어서 재평가를 진행했습니다.
그 결과, 순정 모델은 성능이 0.281로 처참히 무너진 반면, 증강 모델은 0.463이라는 강력한 방어력을 보여주며 압도적인 승리를 거두었습니다. 이로써 도메인 맞춤형 증강 기법이 실제 낡은 도면 환경에서 얼마나 필수적인 로직인지 완벽하게 증명해 냈습니다.

[슬라이드 8: Phase 3. Transfer Learning — 도면 도메인 특징의 OCR 전이]
Phase 3는 텍스트 위치를 찾는 OCR 탐지 실험입니다.
초기에는 가구와 텍스트를 한 번에 학습시키려 했으나, 서로 특징이 충돌하는 문제가 발생했습니다. 이에 따라 OCR만을 분리하는 2-Stage 전이 학습(Transfer Learning)을 도입했습니다.
A실험은 백지상태에서 학습시킨 방식이고, 우측의 B실험은 앞서 메인 모델이 가구와 구조물을 학습하며 '도면 특유의 흑백 선과 구도'를 마스터한 가중치를 가져와 파인튜닝 시킨 결과입니다.
결과표를 보시면, 전이 학습 모델이 고작 8 에폭만에 빠르게 수렴하며, 정확도 향상은 물론 추론 속도도 31%나 빨라지는 압도적인 우위를 보였습니다.

[슬라이드 9: Phase 4. 실전 추론 + Topological Post-processing + JSON 구조화]
Phase 4는 완성된 모델들로 실제 도면을 분석하고 최종 결과물을 뽑아내는 파이프라인입니다.
우선 CLAHE를 이용한 화질 개선 전처리를 거친 뒤, 고해상도 도면에서 객체를 놓치지 않도록 SAHI 슬라이싱 기법으로 촘촘하게 추론했습니다. 
이후 앙상블 융합 단계에서는 단순한 NMS가 아니라, 방 안에 텍스트(OCR)가 포함되는 포함 관계(IoA)를 파악하고 모델 간 확신도(Confidence)를 중재하는 저희만의 로직을 적용했습니다. 
마지막으로 약간 비뚤어진 탐지 박스를 수평/수직으로 맞추는 위상학적 스냅(Snap) 처리를 더해, 하단에 보이시는 것처럼 아주 깔끔하고 구조화된 JSON 데이터를 최종 출력하는 데 성공했습니다.

[슬라이드 10: 레거시 도면 실전 추론 결과]
이 슬라이드는 노이즈와 열화가 심하게 적용된 레거시 도면 테스트셋에 대한 실제 앙상블 추론 결과입니다.
보시다시피 누렇게 변색되고 화질이 깨진 도면 위에서도 출입문, 창호, 욕조, 싱크대 등 핵심 객체들을 놀라울 정도로 성공적으로 탐지해 냈습니다. 
다만, 과거의 구식 건축 기호(Symbol) 패턴이 현재의 학습 데이터와 달라 발생하는 일부 미탐지(False Negative) 현상도 객관적으로 관찰하여 기록했습니다.

[슬라이드 11: 한계 분석 및 Future Work]
마지막으로 저희 파이프라인의 구조적 한계와 앞으로의 로드맵(Future Work)입니다.
가장 시급한 과제는 '실제 축척 반영'입니다. 현재 출력되는 JSON은 화면상의 픽셀 좌표 기준이므로, 향후 도면 하단의 '1:100' 같은 텍스트를 인식하여 실제 물리적 치수(mm/cm)로 역산하는 기능을 추가할 예정입니다.
둘째, 구식 건축 기호 미탐지 문제를 극복하기 위해 옛날 도면을 소량 라벨링하여 파인튜닝(Fine-tuning)을 진행하고자 합니다.
장기적으로는 바운딩 박스(BBox)의 한계를 넘어 완벽한 벽체 연결과 위상 정보를 벡터로 추출할 수 있는 End-to-End 벡터화 모델을 도입하고, 딥러닝 기반의 도면 복원 전처리를 결합하는 방향으로 프로젝트를 고도화해 나갈 계획입니다.

이상으로 2D 아파트 도면 AI 디지털화 파이프라인 구축 프로젝트 발표를 마치겠습니다. 경청해 주셔서 감사합니다.
